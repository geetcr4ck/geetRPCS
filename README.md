## 🚀 Quick Start

**Install** (open **PowerShell**):

```powershell
irm https://bit.ly/geetrpcs | iex
```

> The interactive installer offers **Portable** (standalone) or **Minimal** (requires .NET 8 Runtime) and asks whether to create Desktop / Start Menu shortcuts. Run the same command later to **update** — settings and shortcut preferences are preserved.

**Uninstall:**

```powershell
irm https://bit.ly/geetrpcs-del | iex
```

> 💡 Every dialog, the tray menu, the per-app editor, and the **built-in Help & Guide** (6 localized topics) are inside the app — right-click the tray icon → **❓ Help & Guide** for the full tour without reading docs.

<details>
<summary><b>🛠️ For Developers: Build from Source</b></summary>

Requires the **[.NET 8.0 SDK](https://dotnet.microsoft.com/en-us/download/dotnet/8.0)** on Windows.

```powershell
git clone https://github.com/geetcr4ck/geetRPCS.git
cd geetRPCS

# Portable (recommended): single self-contained EXE
dotnet publish -c Release -r win-x64 -p:PublishSingleFile=true -p:SelfContained=true --output publish/portable

# Minimal: small build, needs .NET 8 Runtime on the target machine
dotnet publish -c Release -r win-x64 -p:PublishSingleFile=false -p:SelfContained=false --output publish/minimal

# Run the test suite (apps.json integrity + language parity)
dotnet run --project Tests
```

Output lands in `publish/portable/` or `publish/minimal/`.

</details>

## ✨ Features

**Core**

- 🎯 **Hybrid detection** — foreground window + taskbar event hook, single instance, ~70 MB working set idle
- 🎨 **Tray icon animation** — 800 ms rotation + brightness pulse on app switch
- 🖱️ **Mouse Energy Detector** — Sleeping / Relaxing / Normal / Focused / Rush shown on your Discord status
- 🎭 **Witty Narrative Engine** — rotating humorous texts via `witty.json` + `{witty_text}` placeholder
- 🛡️ **Automatic private-browsing detection** — Chrome, Edge, Firefox, Brave, Zen in any UI language; titles masked as `**********`
- 🔄 **Sticky presence** + zero input lag + JSON-with-comments support

**Control**

- ⏸️ Pause • 🔒 Private Mode • 📊 Statistics (CSV/JSON export) • 🛠️ Manage Apps
- ✨ **Custom Rich Presence editor** — idle/active templates, buttons, elapsed time, your own Discord Application ID, all from the tray
- ➕ **Add Custom App** from the menu — process name pickers, stored in `settings.json` (survives apps-database updates)
- ⌨️ Five global hotkeys (Pause / Preview / Private / Reload / Stats) and a 14-item Fluent tray menu with System / Dark / Light theme switcher
- 🌐 **23 languages** shipped; English + Bahasa Indonesia fully translated, rest fall back per-key to English

**Customization**

- Dynamic witty texts, custom Discord assets, per-app overrides, per-app timestamps
- Text placeholders: `{app_name}` • `{process_name}` • `{window_title}` • `{witty_text}`
- Two button slots, `http(s)://` URL validation, 32-char label cap — invalid buttons are silently skipped

**Internals**

- 🔇 Silent auto-update (configurable cadence, default off) + auto apps-DB sync
- 🔁 Network retry, shared `HttpClient`, true hot reload of `config.json` / `apps.json`
- 🪵 Centralized logging to `%LOCALAPPDATA%\geetRPCS\geetRPCS.log`
- 🧹 Event-driven memory trims (no scheduled 30-min cycle), FIFO 16-entry preview image cache

> 🆕 **What changed in v1.4.2** — every window and dialog moved to Fluent WPF, browser private/incognito windows are detected automatically, custom Rich Presence is editable from the tray, and idle CPU/RAM dropped (working set 78.4 → 69.3 MB, idle CPU 3.83% → 3.29%).

## ⚙️ Configuration

> 💡 **Prefer the GUI** — the **Custom Rich Presence** and **Manage Apps** tray dialogs cover everything below. The JSON files remain fully supported for power users.

Out of the box geetRPCS works without any config file. Edit [`config.json`](config.json) (auto-created via Quick Actions → **Edit config.json**) only if you want your own Discord Application ID, custom presence text, or custom buttons.

```json
{
  "Discord": {
    "ApplicationId": "YOUR_DEFAULT_DISCORD_APP_ID",
    "Details": "Idling...",
    "State": "Ready to work",
    "ActiveDetails": "Working on {app_name}",
    "ActiveState": "{window_title}",
    "showTimestamps": true,
    "Assets": {
      "LargeImageKey": "geetrpcs-logo",
      "LargeImageText": "geetRPCS v1.4.2",
      "SmallImageKey": "verified",
      "SmallImageText": "Powered by geetRPCS"
    },
    "Buttons": [
      { "Label": "GitHub", "Url": "https://github.com/geetcr4ck/geetRPCS" }
    ]
  }
}
```

**Need a Discord Application ID?** Follow [`docs/CUSTOM_APP_ID.md`](docs/CUSTOM_APP_ID.md) for the step-by-step Discord Developer Portal walkthrough (create app, copy ID, upload art assets).

**Per-app overrides** (large image, per-app App ID, buttons, timestamps) live in [`apps.json`](apps.json) — add a `"clientId"` field to a single entry to switch Discord App IDs dynamically when that app is focused.

> Buttons need `http(s)://` and ≤32-char labels; invalid buttons are skipped silently.

## ❓ FAQ

<details>
<summary><b>Presence not showing on Discord?</b></summary>

1. Use **Discord Desktop** (not the web app).
2. Discord → Settings → Activity Privacy → enable **Display current activity as a status message**.
3. Restart Discord and geetRPCS.
4. Make sure you are not in **Pause** mode.

</details>

<details>
<summary><b>How does the Automatic Apps Database Update work?</b></summary>

On startup geetRPCS checks if your `apps.json` is outdated. If a newer version is published, a one-click prompt offers to update it. Your custom apps are stored in `settings.json`, so app-database updates never remove them.

</details>

<details>
<summary><b>How do I update geetRPCS?</b></summary>

Run the installer command again — it doubles as the updater and preserves your settings:

```powershell
irm https://bit.ly/geetrpcs | iex
```

For automatic updates, enable **Auto-Update** from the tray menu (off by default). geetRPCS then checks for new releases periodically (~every 6 hours) and can notify you, show a dialog, or install silently depending on the selected mode.

</details>

<details>
<summary><b>Where are my config, stats, and log files?</b></summary>

```
📁 %LOCALAPPDATA%\geetRPCS\
├── config.json        # optional Discord RPC configuration
├── settings.json      # user settings & custom apps
├── statistics.json    # usage statistics
└── geetRPCS.log       # log file

📁 Install folder (next to geetRPCS.exe)
├── apps.json          # application database
├── witty.json         # witty texts
└── Languages/         # translation files
```

</details>

## 🛡️ Security

**100% open source (Apache 2.0)** — inspect every line in this repository.

Some antivirus products may flag the EXE as a false positive because geetRPCS uses low-level Windows APIs by design:

- **Global hotkey hook** (`RegisterHotKey`) — for the 5 system-wide shortcuts
- **Mouse hook** (`SetWindowsHookEx`) — for the Mouse Energy Detector (fully uninstalled when the feature is off)
- **Foreground-window event hook** — for accurate per-app detection
- **Discord IPC socket** — for Rich Presence updates
- **Auto-start registry key** — opt-in, managed from the tray menu
- **GDI+ tray icon rendering** — for the rotation animation

Verify the binary on [VirusTotal](https://www.virustotal.com) or whitelist it in your security software.
